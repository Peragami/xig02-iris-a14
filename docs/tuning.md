# 軽量・省電力チューニング

最優先の3本柱のうち「軽量」と「省電力」の具体策。両立するものを優先し、トレードオフがあるものは適応型にする。

## 軽量：実重量

- low_RAM 設定を適用する（RAM 4GB 端末向け）
- ZRAM / LMKD を端末に合わせて調整する
- 不要なシステムアプリ・常駐サービスを削減する
- Googleアプリは最小構成（Play開発者サービス + Playストア + Googleサービスフレームワークの3点のみ）

## 軽量：体感

- アニメーション倍率の初期値を 0.5 倍にする（ウィンドウ／遷移／Animator）
- ぼかし（ブラー）効果を無効にする。通知シェードや履歴画面のブラーは Snapdragon 480 の GPU には重く、カクつきの原因になる
- ランチャーと SystemUI はメモリに常駐させ、アプリ切替がキャッシュから戻るようにする（LMK で殺しすぎない）
- アプリ起動のスプラッシュと遷移はシンプルにする

## 省電力

- Doze とアプリ待機（App Standby）の制限を強め、画面オフ中の無駄な起床（wakelock）を減らす
- Wi-Fi / Bluetooth の位置情報スキャンを OFF にする
- 5G は常時固定にせず、4G優先／自動切替寄りにする（SIM運用時）
- 使わない機能は切る（FeliCa は対象外として無効化する方針と一致）

## トレードオフと決め事

| 項目 | 決め事 | 理由 |
|---|---|---|
| リフレッシュレート | 90Hz固定にせず適応型（スクロール中は高く、静止時は落とす） | 90Hz固定は体感は良いが電池を食う |
| CPUブースト | タッチブーストは短く最小限 | 反応と電池の両立 |
| アプリ常駐 | ランチャー／SystemUI と使用頻度の高いものだけ | 常駐を増やすとメモリも電池も食う |

## 注意

- この端末のディスプレイは液晶なので、ダークモードや黒壁紙は有機ELほどの節電効果は無い。節電の主戦場は画面の明るさ・点灯時間とバックグラウンド消費
- 効果は実機で測る（起動時間、アプリ起動、メモリ使用量、画面オフ中の電池減少）。測れない調整は採用しない

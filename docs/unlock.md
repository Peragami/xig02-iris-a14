# ブートローダーアンロック手順

## 前提（2026-11-18 時点で完了済み）

- 開発者オプション: 有効化済み
- Miアカウント: 今の電話番号の番号ではなく端末上で新規作成したアカウントでログイン中
  （電話番号は Redmi 時代から変わっているため、旧アカウントは使わない）
- Mi Unlock status: 「正常に追加されました」と表示され、紐付け成功
- SIM: 紐付け時は Pixel 10 の物理SIM（au）を Redmi へ移植して実施。紐付け後は Pixel へ戻してよい

## 解禁目安

- 標準の168時間待ちなら 2026-11-25 11:09頃
- 正確な残り時間は、PC の Mi Unlock Tool で試したときに表示される時間が正

## 待ち期間中にやってはいけないこと

- Redmi の Miアカウントをサインアウトする
- 端末を初期化する

## アンロック当日の手順

1. 端末のデータをバックアップする（アンロックで全消去される）
2. Redmi を Fastboot モードで起動する
3. Windows PC で Mi Unlock Tool を開き、紐付けに使ったのと同じ Miアカウントでサインインする
4. Unlock を実行する
5. Tool に残り時間が表示された場合は、その時間が正確な解禁時刻。無理に進めず待つ

## 既知の制約

- LineageOS 公式対応は無い（日本専売モデルで海外版が無いため）
- iris 用の非公式 device tree と XIG02 専用非公式 LineageOS の先行事例は存在する
- Treble / GSI は利用可能とされる
- カスタムROMでは FeliCa / おサイフケータイと eSIM が動作しない可能性が高い
- 公式アップデートは Android 13 / MIUI 14 が最後（キャリアOTAのみで、公式フルROMの公開は無い）

# 純正への復元（リストア）

アンロック直後に取った全パーティションダンプを使い、端末を純正状態
（V14.0.23.0）に戻すための手順と、できること／できないことの整理。

## 結論

- **純正 ROM への復元は可能。** それがダンプを取る目的そのもの
- ただし「購入時の完全な姿」にはならない。限界は下記の通り

## 戻せるもの

- system / vendor / product などを含む **super** ごと純正イメージに戻る
- boot、dtbo、vbmeta、モデム系、persist 等もダンプ時点の純正に戻る
- 結果として純正 MIUI（V14.0.23.0）が起動する状態に戻せる

## 戻せないもの・注意

- **ユーザーデータは戻らない。** アンロック時点で全消去される上、
  userdata はダンプ対象外（暗号化済み）。アプリや設定は最初から入れ直し
- **ブートローダーの再ロックは絶対にしない。**
  XIG02 には Xiaomi 公式の Fastboot ROM が存在しないため、
  公式の「焼いて再ロック」手順が使えない。再ロックは文鎮化リスクが
  高いので禁止（safety.md）。復元後もアンロック警告表示は残る
- **product の読み出し異常箇所の扱い。** ダンプ時に読み出しエラーが
  出た領域はゼロ埋めで記録される。そのダンプから復元すると当該領域も
  ゼロで戻るため、完全な復元にならない可能性がある。
  アンロック当日の生読み出しテスト（unlock-day.md 手順6）の結果で
  重大度が確定する。生読みで読めればダンプは正常で、この問題は消える

## 手順

1. 復元に使うダンプフォルダを用意する（2か所コピーのどちらか。
   manifest.txt が入っていること）
2. 端末を fastboot モードで起動し、USB 直挿しで接続。電池 50% 以上
3. まずドライランで検証だけ行う：
   `tools\restore-partitions.bat <ダンプフォルダ>`
   - product = iris の確認、全ファイルのサイズと SHA256 が
     manifest と一致するかを確認し、書き込み計画を表示して終わる
4. 検証が通ったら書き込み実行：
   `tools\restore-partitions.bat <ダンプフォルダ> WRITE`
   - 確認入力（YES、ダンプに読み出しエラーがある場合は RESTORE）
     をしないと書き込まない
   - 論理パーティション（system 等）は super に含まれるため個別には
     焼かず、super を丸ごと焼く
   - 途中で失敗したら再起動せず fastboot のまま相談すること
5. 再起動して純正 MIUI が起動することを確認する
   - 起動ループする場合はリカバリから初期化（factory reset）して再確認
     （カスタム ROM 側の userdata が残っていると純正が起動できない
     ことがあるため。これはデータ復元とは無関係の初期化）

## 復元後に残る差分

- ブートローダーはアンロックされたまま（起動時に警告表示）
- 端末内のデータは空（純正の初期セットアップから）
- それ以外（OS・ファームウェア）はダンプ時点の純正と同一
